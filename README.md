
# 🎮 Number Guessing Game

A simple and interactive **Number Guessing Game** built with Python. The computer randomly selects a number between 1 and 100, and the player must guess the correct number.

The game provides hints after every guess, helping players find the correct number.

## 🚀 Features

- 🎲 Random number generation (1–100).
- ⬆️ Get hints when your guess is too low.
- ⬇️ Get hints when your guess is too high.
- 🔄 Continuous guessing until the correct number is found.
- 🏆 Tracks the number of attempts.
- 💻 Simple command-line interface.

## 🛠️ Technologies Used

- Python 3
- Random Module
- While Loop
- Conditional Statements (if, elif)
- User Input

## 🎯 How to Play

1. Run the Python program.
2. Enter a number between 1 and 100.
3. Follow the hints:
   - Higher number please.
   - Lower number please.
4. Keep guessing until you find the correct number.
5. See how many attempts you needed!

## 💡 Example Output

```text

Lower number please

Guess the number: 25

```

*Note: The actual number and attempts will vary in each game.*
